Frequently Asked Questions

Everything you need to know about working with HAVEN.

Do I have to pay monthly hosting fees?

No! Because HAVEN crafts pure static HTML, CSS, and JS architecture, your site can be hosted 100% for free on GitHub Pages, Cloudflare Pages, or AWS S3 with zero recurring server charges.

Can I connect my own custom domain?

Yes. We configure your DNS records to route your custom domain (e.g. yourbrand.com) with automatic SSL certificates and global CDN caching.

Who owns the code and intellectual property?

You do. Upon project completion, all repository code, assets, typography licenses, and designs belong 100% to you. No vendor lock-in whatsoever.
